房东许可证

它是面向租客 / 家庭的入住许可。某些私人房源广告里会直接写 huisvestingsvergunning vereist。

什么是 WWS 住房点数

WWS（Woningwaarderingsstelsel）可以理解成荷兰的“住房租金评分”。 房屋面积、能源表现、WOZ 房产价值、厨房 / 卫浴设施、室外空间等都会形成点数。点数越高，法律允许的最高基础租金通常越高。

遇到涉及住房许可或租金上限的房源时，可向房东或中介索取 WWS puntentelling，也可使用 Huurcommissie 的 Huurprijscheck。

Huurprijscheck →
≤143 点社会租赁2026 最高基础租金 €932.93
144–186 点中等租赁最高到 €1,228.07
≥187 点自由市场通常高于 €1,228.07

这里的金额指 kale huur / 基础租金，不是含 servicekosten、水电网后的总价。

1
看房型你租的是独立住宅吗？

例如自己有厨房、厕所 / 浴室的 studio、公寓或整套住宅。普通单间、共享厨卫通常属于非独立住房，不按这里这套住房许可逻辑判断。

看 WWS / 基础租金≤186 WWS 点，或者 kale huur ≤€1,228.07？

是“或者”，不是“同时”。 只要其中一项触发，就要继续核对海牙住房许可。

3
看本人情况收入、家庭人数、面积是否符合？

2026 年主要看应税年收入、每人至少 12㎡ 等条件；低租金的大户型还可能有最低家庭人数要求。

虽然点数高于 186，但租金低于 €1,228.07 → 仍要检查住房许可。

例子 B180 points + €1,400 kale huur

虽然租金更高，但点数 ≤186 → 仍要检查住房许可。

看到房源写着 huisvestingsvergunning vereist，怎么做？
  1. 正常联系 / 申请房源
  2. 问清 kale huur 与 WWS 点数
  3. 对照收入、家庭人数和面积条件
  4. 准备租约 / 房东声明和收入证明等材料
  5. 向 Gemeente Den Haag 申请；BRP 仍是另一项手续
2026 实操：申请费 €56.75；材料完整时市政府通常在 2 周内回复。明明需要许可却未申请，可能被罚 €410。

工作人士找房

工作人士找房时房东 / 中介更看重收入稳定性和申请材料；因此一定要提前准备好申请材料。

找房路线

准备申请材料，并根据工作地点同时关注私人市场、住房运营商和 Haaglanden 周边。

STEP 1准备申请包身份证明、居留 / 工作权限、雇佣与收入材料先整理。

STEP 3按通勤扩圈Centraal、HS、International Zone 不同工作点对应不同搜索方向。

区域大致类型找房时怎么理解建议
Bezuidenhout住宅 / 通勤靠近 Centraal，住宅与办公混合，通勤方便。越靠车站和主干道，商业、人流和噪音越明显。
Statenkwartier / Benoordenhout成熟住宅国际机构与使馆方向常见选择，整体更偏住宅型。通常预算要求更高；仍按具体街道判断。
Scheveningen住宅 + 旅游海边生活方式明显，住宅区与游客区混在一起。夏季游客、停车和噪音差异更大；短租还要单独确认 BRP。
Centrum城市混合交通、餐饮、商业都方便，但夜间活动也更多。留意楼下商业、酒吧、街道噪音和自行车停放。
Stationsbuurt / HS 周边交通枢纽通勤非常方便、人流复杂。市政府 2026 年仍把 Stations- / Rivierenbuurt 的 leefbaarheid、安全与公共秩序作为治理重点。准备申请前建议晚上再走一次。
Laak / Laakhavens学生 + 住宅混合靠 THUAS，价格与学生房源有吸引力；官方 wijkagenda 也提到部分位置居民安全感、照明和街面秩序问题。不要只看“离学校近”，要看具体楼和周边几条街。
Rijswijk / Voorburg周边住宅不属于 Den Haag 市政府，但常被纳入海牙找房通勤圈。重点比较车站 / tram / 骑行到学校或公司的总时间。
如果你还没来荷兰：可查看 Street View、车站 / 商业分布和 Den Haag in Cijfers 的 wijk / buurt 信息；签约前尽量在不同时段核验周边，或请当地联系人协助。

短租与 BRP 地址登记

家具房、short stay 和转租的登记条件可能不同，应确认具体地址和合同能否用于正式居住登记。

  • 合同是否写明完整出租地址与租期
  • 发布者是否明确允许 BRP / inschrijven，并愿意书面确认
  • 如果是二房东转租，原合同或产权人是否允许转租
  • 分别核对住房许可和 BRP 地址登记

海牙租房合同检查

快速检查

  • 出租人、租客、地址和实际看房地址是否一致
  • 基础租金（kale huur）、servicekosten、水电网等是否拆开写清
  • 合同期限、开始日期、解约方式和押金是否明确
  • 独立住宅：WWS / kale huur 是否触发 huisvestingsvergunning
  • 短租 / 转租：是否允许 BRP，发布者是否有出租权限
  • 区域：按具体地址计算通勤，并在不同时间看一次周边环境

BRP ≠ 住房许可

“可以注册地址”不代表这套房不需要 huisvestingsvergunning；两项分别核对。

检查中介费

如果中介是替房东出租同一套房，不能把“一个月租金 + VAT”默认视为租客应付的标准费用。
