# 项目结构与后续维护

## 分层职责

```text
app.py                         本地运行入口
wsgi.py                        应用服务器入口；不代表已经部署
expatus/__init__.py            Flask 应用工厂、蓝图注册、请求生命周期
expatus/config.py              环境配置与本地安全默认值
expatus/database.py            SQLite/Turso 连接、兼容层、增量迁移
expatus/constants.py           平台目录与房源状态常量
expatus/controllers/           页面、账户、工作台、表单、管理后台 HTTP 入口
expatus/repositories/          按领域封装 SQL 查询
expatus/services/              验证、邮件、安全、审计、时间处理
templates/pages/               已确认的前台 HTML 页面
templates/admin/               管理后台页面
templates/partials/            所有页面复用的导航、页脚、后台导航
static/css/src/                样式源文件
static/css/dist/               构建后的独立页面样式
static/js/                     独立页面脚本和共享交互
tools/                         CSS 构建、工程检查与过期数据清理
tests/                         本地自动化功能测试
```

控制器负责读取 HTTP 请求、校验权限并组织响应；SQL 只放在数据访问层或数据库维护工具；安全规则、邮件、审计和输入清理放在可复用服务中。增加功能时，优先补一个领域 repository、对应 controller 和页面模板，不要把业务重新堆回 `app.py`。

## 数据库与现有数据

本地默认固定为 `DATABASE_BACKEND=sqlite`，数据库文件为 `data/expatus-local.db`。就算系统环境里已经存在 Turso 凭证，只要没有明确切换数据库后端，也不会连接正式数据库。

正式数据库的旧表名和主要字段保持兼容；新增隐私确认字段、最近登录字段、策略生成记录、审计日志和频率限制表均采用增量创建。迁移不删除旧用户或旧房源记录。切换到正式数据库属于未来上线阶段，需要单独备份、演练并安装 `requirements-turso.txt`；本包不会执行上线。

## 账户和个人工作台

- 账户密码仅保存安全哈希，邮箱验证码只保存不可逆摘要。
- 新用户必须确认已阅读隐私声明；旧用户首次登录时补充确认。
- 可选访问分析与账户注册无关，不同意分析仍可使用账户。
- 策略规则集中在 `expatus/services/strategy_engine.py`。浏览器只提交资料和展示后端返回的结构化结果，不保存第二套判断规则。
- 策略生成由服务端控制每日次数，记录结果及引擎版本保存在用户自己的账户下；普通房源进度同步会按当前状态重新计算，不消耗生成次数。
- 进度摘要只读取当前登录用户的当前房源状态，不从历史操作日志恢复已经退回的 Viewing 等里程碑。
- 策略页读取房源工作台的真实进度，并在再次访问时恢复最近一次生成结果。
- 用户可以在隐私声明页下载自己的资料或删除账户及关联数据。

## 表单与后台安全

所有写操作经过 CSRF 验证。公开表单具备隐藏诱捕字段、请求频率限制、文本长度控制、链接数量限制和危险标签拒绝。数据库查询统一参数化。后台 CSV 导出会处理以 `= + - @` 开头的内容，避免电子表格公式注入。

后台只保留现阶段必要信息：用户账户、成功/失败登录、注册、策略生成、房源关键操作、联系留言和租房问题。IP 地址只保存不可逆哈希，不保存密码、验证码、完整留言或证件文件到审计日志。

## 域名和分析隔离

`BASE_URL` 默认为 `https://www.expatus.nl`，所有 canonical、sitemap 和 robots 使用这一地址。启用 `ENFORCE_CANONICAL_HOST` 后，应用会将 `expatus.nl` 请求永久重定向到 `www.expatus.nl`。本地运行时关闭这一检查，避免影响 `127.0.0.1`。

分析脚本只有在**生产环境 + 显式启用 + 非后台会话 + 用户主动同意**全部成立时才加载。广告存储与广告个性化始终关闭。
