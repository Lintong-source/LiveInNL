# 本地测试建议

## 页面与导航

- 检查首页、莱顿、海牙、租房渠道、找房攻略、租房材料、Plan B、退租押金、联系我们和隐私声明。
- 分别在电脑和手机宽度检查顶部导航、共享页脚、工作台入口和已有样式。
- 检查旧 `.html` 地址是否跳转到对应的新页面。
- 打开 `/robots.txt` 和 `/sitemap.xml`，确认全部公开网址使用 `www.expatus.nl`。

## 账户与隐私

- 使用测试账号登录；再注册一个新邮箱，检查页面展示的本地验证码。
- 不勾选隐私声明时尝试注册，确认服务器拒绝。
- 测试密码错误、密码找回、退出登录，以及登录后导航状态。
- 打开隐私声明，下载账户 JSON，最后使用一个单独测试账号验证删除账户。
- 打开浏览器 Network 面板，确认本地浏览不会加载 `googletagmanager.com` 或发送 GA4 请求。

## 工作台

- 添加房源、修改来源和租金、更新跟进状态、停止跟进、恢复和删除。
- 首页收藏平台后检查“我的收藏”；取消收藏后确认列表同步。
- 生成找房策略，确认页面再次打开时会恢复最近一次结果。
- 连续生成 3 次后，第 4 次应由服务器拒绝；不同账号拥有独立计数。
- 检查策略页对应平台链接和城市指南可以实际打开。

## 公开表单和后台

- 正常提交联系留言与退租问题；故意输入脚本标签、过多链接或错误邮箱，确认被拒绝。
- 访问 `/admin` 并用本地后台密码登录。
- 查看用户、登录失败日志、活动日志、策略记录、留言和租房问题。
- 下载 CSV，检查中文正常显示；对于以公式字符开头的内容，确认已经安全转义。

## 清理

- 如需重置本地测试数据，停止服务后删除 `data/expatus-local.db`，再次启动会自动生成一个新的本地数据库和测试账户。
- 不要删除或修改正式 Turso 数据库；本地默认不连接正式数据库。
